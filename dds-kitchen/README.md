# DD's Kitchen 🥣🔥✨

Welcome to the official repository of **DD's Kitchen**, a premier gourmet meal delivery experience built with Next.js, Supabase, and Framer Motion.

## 🥘 Features
- **Discovery**: Explore daily chef-crafted gourmet specials.
- **Scheduling**: Real-time kitchen calendar with live serving status.
- **Seamless Payments**: Secure UPI intent-based checkout.
- **Admin Dashboard**: Zero-latency order pipeline and mission management.

## 📲 Get Started
To view the kitchen in action, visit: [https://dhee-s.github.io/App/](https://dhee-s.github.io/App/)

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Database**: Supabase (PostgreSQL + Realtime)
- **Styling**: Vanilla CSS + Framer Motion
- **Icons**: Lucide React
- **Hosting**: GitHub Pages via GitHub Actions
