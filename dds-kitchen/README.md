## 🥘 Specialized Features
- **✨ Client Component SWR Integration**: Near-instant navigation with fresh data polling.

- **🚀 UPI Intent Workflow**: Optimized for one-tap payments on mobile.

## 🛠️ Build & Development
Built with **Node 20+** and **Next.js 16 (Turbopack)**.

```bash
# Install dependencies
npm install

# Run development server with Turbopack
npm run dev

# Build for production
npm run build
```
